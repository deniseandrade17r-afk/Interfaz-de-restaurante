# Interfaz-de-restaurante
Interfaz de restaurante con menú y ordenes de clientes

Realizado por: 
- Sánchez Valenzuela Natalia Guadalupe 
- Rodriguez Andrade Denise Abigail

En este trabajo se implementó una interfaz para un restaurante de comida italiana. El sistema muestra cómo el cliente interactúa con la plataforma para enviar sus órdenes directamente a la cocina, sin necesidad de que un mesero tome las ordenes.

Funcionalidades del sistema:

- Menú por categorías: Desayunos, comidas, cenas, bebidas y postres.
- Filtros e información nutricional: Opciones vegetarianas, sin gluten y sin azúcar, además de recomendaciones del chef, desglose de calorías, descripción de preparación y especificaciones detalladas de cada platillo o bebida.
- Personalización de órdenes: Pantalla para agregar notas o especificaciones detalladas sobre qué ingredientes quitar o añadir al pedido.
- Confirmación y estado: Modales y ventanas de aviso para confirmaciones, errores y selección de cantidades.
- Finalización del pedido: Pantalla final que muestra el tiempo estimado de entrega de la orden y la opción para realizar un pedido adicional.
